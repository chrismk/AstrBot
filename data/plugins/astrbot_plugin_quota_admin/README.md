# 通用配额系统管理插件 v2.0

标准化跨平台交互插件，支持按钮模式和会话模式，提供配额查询、积分管理、会员管理等功能。

## 🌟 v2.0 新特性

- ✅ **跨平台统一交互** - 自动适配按钮模式（Telegram/Discord）和会话模式（飞书/QQ/微信等）
- ✅ **飞书平台优化** - 自动清理旧消息，界面更整洁
- ✅ **回调路由支持** - 按钮点击即时响应
- ✅ **会话管理优化** - 使用通用 SessionManager，更稳定可靠
- ✅ **响应构建器** - 统一的响应构建，代码更简洁
- ✅ **速率限制查看** - 管理员可查看限流状态
- ✅ **统计分析增强** - 更丰富的数据统计

## 功能特性

### 👤 用户功能

- **我的配额** - 查询当前配额状态
- **我的积分** - 查询积分余额和流水
- **我的会员** - 查询会员信息和到期时间
- **使用记录** - 查询历史使用记录
- **兑换配额包** - 使用积分兑换配额包（多轮对话）

### 👑 管理员功能

- **配额管理** - 进入配额管理面板（多轮对话）
  - 重置用户配额
  - 添加配额加成
  - 查看配额统计
- **充值积分** - 为用户充值积分
- **升级会员** - 为用户升级会员
- **查询用户** - 查询用户详细信息

## 命令列表

### 用户命令（仅需记住2个）

```
/我        查询我的信息（配额/积分/会员/兑换）
/帮助      显示帮助信息
```

### 管理员命令

```
/管理      管理面板（用户/积分/会员/统计/限流）
/帮助      显示帮助信息
```

> 💡 **按钮模式**（Telegram/Discord）：点击按钮即可操作，无需输入数字  
> 💡 **会话模式**（飞书/QQ/微信等）：按提示输入数字选择，回复 0 退出

## 配置说明

编辑 `config.yaml` 文件：

```yaml
# 管理员列表（用户ID）
admins:
  - "admin_user_id_1"
  - "admin_user_id_2"

# 插件设置
settings:
  # 会话超时时间（分钟）
  session_timeout: 10
  
  # 是否启用配额包兑换
  enable_redeem: true
  
  # 是否启用管理员功能
  enable_admin: true
```

### 配置管理员

将管理员的用户ID添加到 `admins` 列表中：

```yaml
admins:
  - "123456789"  # 管理员1的用户ID
  - "987654321"  # 管理员2的用户ID
```

## 技术特性

### 跨平台支持

- **按钮模式**（Telegram/Discord）
  - 自动显示内联按钮
  - 点击按钮即时响应
  - 自动编辑消息更新界面
  
- **会话模式**（飞书/QQ/微信/钉钉等）
  - 数字选择交互
  - 飞书平台自动清理旧消息
  - 统一的导航提示

### 会话管理

- 使用通用 `SessionManager` 管理会话
- 自动超时（5分钟）
- 会话续期机制
- 类型化处理器注册

### 响应构建

- 继承 `BaseResponseBuilder`
- 自动适配平台能力
- 统一的响应格式
- 优雅的功能降级

### 权限管理

- 用户命令：所有用户可用
- 管理员命令：仅配置的管理员可用
- 自动权限检查和提示

### 数据安全

- 所有操作记录日志
- 积分充值/消费有完整流水
- 配额操作可追溯
- 幂等性保证（防止重复充值）
- 原子操作（并发安全）

## 依赖要求

- AstrBot >= 3.0.0
- 通用配额系统 (common)

## 安装说明

1. 将插件放置到 `data/plugins/astrbot_plugin_quota_admin/` 目录
2. 编辑 `config.yaml` 配置管理员列表
3. 重启 AstrBot

## 注意事项

1. **管理员配置**：首次使用前必须配置管理员列表
2. **会话超时**：会话在10分钟后自动过期
3. **积分操作**：积分充值/消费操作不可撤销，请谨慎操作
4. **配额重置**：重置配额会删除当日使用记录，请确认后操作

## 常见问题

### Q: 如何获取用户ID？

A: 用户ID是平台分配的唯一标识，可以通过以下方式获取：
- Telegram: 用户的数字ID
- QQ: QQ号
- 其他平台: 查看平台文档

### Q: 配额包兑换后多久生效？

A: 配额包兑换后立即生效，有效期从兑换时刻开始计算。

### Q: 会话超时后需要重新开始吗？

A: 是的，会话超时后需要重新发送命令开始新的会话。

### Q: 管理员命令为什么提示权限不足？

A: 请检查：
1. 用户ID是否正确添加到 `config.yaml` 的 `admins` 列表
2. 配置文件是否正确保存
3. 是否重启了 AstrBot

# 快速开始指南

## 🚀 5分钟上手

### 1. 配置管理员

编辑 `config.yaml`，添加管理员用户ID：

```yaml
admins:
  - "your_user_id_here"
```

### 2. 重启 AstrBot

重启后插件自动加载。

### 3. 开始使用

## 📱 用户只需记住3个命令

```
/我      - 查询我的信息
/兑换    - 兑换配额包
/帮助    - 显示帮助
```

## 👑 管理员只需记住2个命令

```
/管理    - 管理面板
/帮助    - 显示帮助
```

## 💡 使用技巧

### 用户操作流程

```
1. 发送 /我
2. 选择要查询的信息（输入数字1-4）
3. 查看结果
```

### 管理员操作流程

```
1. 发送 /管理
2. 选择操作类型（输入数字1-6）
3. 按提示逐步输入信息
4. 完成操作
```

## ⚡ 快捷退出

在任何多轮对话中，回复以下内容可随时退出：
- `0`
- `取消`
- `q`
- `Q`

## 🎯 设计理念

### 简化命令
- **用户**：只需记住 `/我` 和 `/兑换`
- **管理员**：只需记住 `/管理`

### 多轮对话
- 所有复杂操作都通过多轮对话完成
- 无需记忆复杂的命令参数
- 按提示逐步操作即可

### 友好提示
- 每一步都有清晰的提示
- 支持随时退出
- 错误提示友好明确

## 🔧 故障排除

### Q: 提示"配额系统未初始化"？

A: 检查通用配额系统是否正确安装在 `data/plugins/common/` 目录。

### Q: 提示"权限不足"？

A: 检查用户ID是否正确添加到 `config.yaml` 的 `admins` 列表。

### Q: 会话超时？

A: 会话默认10分钟超时，超时后需要重新发送命令开始新会话。

### Q: 如何获取用户ID？

A: 不同平台的用户ID获取方式：
- **Telegram**: 用户的数字ID
- **QQ**: QQ号
- **其他平台**: 查看平台文档

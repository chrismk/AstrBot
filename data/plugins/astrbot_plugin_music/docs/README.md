# 🎵 AstrBot 音乐搜索插件

一个功能强大的音乐搜索和推送插件，支持多平台音乐搜索、智能配额管理和文件缓存。

## ✨ 核心特性

### 🔍 智能搜索
- 支持网易云音乐、QQ音乐、酷我音乐
- 关键词模糊搜索，精准匹配
- 分页浏览，每页10条结果
- 交互式序号按钮选择

### 🎼 多音质支持
- **HiRes/Master**：最高音质（5配额）
- **无损FLAC**：无损音质（3配额）
- **高品质320K**：高品质（2配额）
- **标准128K**：标准音质（1配额）

### 💎 File ID 缓存系统 ⭐ 优化升级
- 智能缓存 Telegram file_id
- 二次请求秒发，节省流量
- **永久保存**，最大化缓存命中率
- 自动标记失效缓存，智能回退
- 支持多平台、多音质缓存

### 📊 配额管理
- 每日配额限制，防止滥用
- 普通用户：10配额/天
- VIP用户：50配额/天
- 管理员：无限配额

### 🚀 大文件支持 + URL 直发 ⭐
- 使用自建 Telegram Bot API 服务器
- 突破官方 50MB 文件大小限制
- 支持最大 2GB 音频文件
- **直接发送音频URL**，无需本地存储

## 🚀 快速开始

### 安装步骤

1. **克隆或下载插件**

```bash
cd data/plugins/
git clone <repository_url> astrbot_plugin_music
```

2. **配置文件**

编辑 `config.yaml`：

```yaml
# Music API Server 配置
music_api:
  base_url: "http://43.129.194.21:19003"
  api_key: "YOUR_API_KEY_HERE"  # 向管理员获取

# Telegram Bot API 配置
telegram_api:
  api_server: "http://168.138.42.230:19009"

# 管理员配置
quota:
  admin_users:
    - "123456789"  # 你的 Telegram user_id
```

3. **安装依赖**

```bash
pip install -r requirements.txt
```

4. **重启 AstrBot**

```bash
astrbot restart
```

## ⚙️ 配置说明

### 配额规则

```yaml
quota:
  rules:
    hires: 5      # HiRes/Master 音质
    lossless: 3   # 无损 FLAC
    exhigh: 2     # 高品质 320K
    standard: 1   # 标准 128K
  
  levels:
    normal: 10    # 普通用户每天10配额
    vip: 50       # VIP用户每天50配额
    admin: -1     # 管理员无限
```

### File ID 缓存 ⭐ 永久存储

```yaml
file_cache:
  enabled: true              # 启用缓存
  permanent_storage: true    # 永久保存，不清理
  stats_enabled: true        # 启用统计
```

### Telegram API

```yaml
telegram_api:
  api_server: "http://168.138.42.230:19009"  # 自建服务器
  use_custom_server_for_large_files: true    # 大文件使用自建服务器
  large_file_threshold: 52428800             # 50MB阈值
```

## 🗂️ 数据库结构

插件使用 SQLite 数据库存储：

1. **user_download_history**：用户下载历史
2. **user_quota_config**：用户配额配置
3. **telegram_file_cache**：Telegram file_id 缓存

数据库位置：`./user_quota.db`

## 🔧 技术架构

### 核心模块

- `main.py` - 主插件逻辑
- `quota_manager.py` - 配额管理
- `file_cache_manager.py` - File ID 缓存
- `music_api.py` - Music API 封装
- `telegram_bot_api.py` - Telegram API 封装

### 工作流程

```
搜索 → 翻页 → 选择歌曲 → 查看详情 → 选择音质
  ↓
检查配额 → 查询缓存
  ↓
有缓存 → 直接发送（秒发）
  ↓
无缓存 → 下载 → 上传 → 保存 file_id → 发送
  ↓
扣除配额 → 记录历史
```

### File ID 缓存机制

```
用户请求音频
  ↓
查询数据库：SELECT file_id WHERE song_id=? AND quality=?
  ↓
  ├─ 有缓存 → 验证有效性 → 直接发送 → 更新使用时间
  └─ 无缓存 → 下载文件 → 上传 → 保存 file_id → 发送
```

## ⚠️ 注意事项

### 1. API Key 获取

需要向 Music API Server 管理员申请 API Key。

### 2. Telegram Bot Token

确保你的 Bot Token 在自建 API 服务器上已配置。

### 3. 文件大小限制

- 官方 API：最大 50MB
- 自建 API：最大 2GB

### 4. 配额说明

- 配额每天 0 点自动重置
- 不同音质消耗不同配额
- 管理员可手动重置配额

### 5. 缓存管理

- File ID 可能因 Telegram 服务器清理而失效
- 插件会自动验证并标记失效缓存
- 定期自动清理超过 30 天未使用的缓存

## 🐛 故障排查

### 问题：搜索无结果

**原因**：
- API Key 错误或过期
- Music API 服务器不可达
- 网络连接问题

**解决**：
1. 检查 `config.yaml` 中的 API Key
2. 测试 API 服务器连通性
3. 查看日志文件 `music_plugin.log`

### 问题：文件发送失败

**原因**：
- Telegram API 服务器不可达
- Bot Token 无效
- 文件过大（超过 2GB）

**解决**：
1. 检查自建 API 服务器状态
2. 验证 Bot Token
3. 查看错误日志

### 问题：配额统计不准确

**原因**：
- 数据库损坏
- 并发写入冲突

**解决**：
1. 备份并修复数据库
2. 重启插件
3. 联系管理员重置

# 签到系统插件

一个功能丰富的签到系统，支持每日签到、连续签到奖励、补签、排行榜等功能。

## ✨ 功能特性

### 🎯 核心功能

1. **每日签到** - 每天签到获取积分奖励
2. **连续签到奖励** - 连续签到天数越多，奖励越丰厚
3. **补签功能** - 使用积分补签漏签的日期
4. **签到排行榜** - 展示连续签到和累计签到排行
5. **每月全勤奖** - 当月全勤额外奖励
6. **幸运签到** - 随机触发双倍奖励
7. **签到统计** - 个人签到历史和统计数据

### 💰 奖励机制

#### 基础奖励
- 固定积分：10积分（可配置）
- 随机积分：1-20积分（可配置）

#### 连续签到加成
| 连续天数 | 奖励倍数 |
|---------|---------|
| 3天 | x1.2 |
| 7天 | x1.5 |
| 15天 | x2.0 |
| 30天 | x3.0 |

#### 特殊奖励
- **幸运签到**：10%概率触发，奖励翻倍
- **全勤奖**：本月全勤额外200积分

### 🔧 补签功能
- 消耗积分：50积分/次（可配置）
- 可补签天数：最近7天
- 补签不影响连续签到天数

## 📋 命令列表

### 用户命令（仅需记住2个）

```
/签      签到（多轮对话）
/帮助    显示帮助信息
```

**💡 /签 命令说明**：
- **今日未签到**：直接完成签到
- **今日已签到**：显示功能菜单
  - 1. 补签
  - 2. 签到记录
  - 3. 签到排行

> 所有功能通过多轮对话完成，无需记忆复杂命令！

### 管理员命令

```
/签到管理     签到管理面板（建议集成到 /管理）
```

## ⚙️ 配置说明

编辑 `config.yaml` 文件：

```yaml
# 管理员列表
admins:
  - "your_admin_user_id"

# 签到奖励配置
rewards:
  base_points: 10              # 基础奖励
  random_points_min: 1         # 随机奖励最小值
  random_points_max: 20        # 随机奖励最大值
  
  # 连续签到奖励倍数
  streak_bonus:
    3: 1.2
    7: 1.5
    15: 2.0
    30: 3.0
  
  perfect_month_bonus: 200     # 全勤奖励
  lucky_chance: 0.1            # 幸运概率（10%）
  lucky_multiplier: 2.0        # 幸运倍数

# 补签配置
makeup:
  enabled: true                # 是否启用
  cost: 50                     # 消耗积分
  max_days: 7                  # 最多补签天数

# 排行榜配置
leaderboard:
  top_count: 10                # 显示人数
```

## 📊 数据库结构

### checkin_records 表
```sql
CREATE TABLE checkin_records (
    id INTEGER PRIMARY KEY,
    user_id TEXT NOT NULL,
    checkin_date DATE NOT NULL,
    points_earned INTEGER NOT NULL,
    is_lucky BOOLEAN DEFAULT 0,
    is_makeup BOOLEAN DEFAULT 0,
    streak_days INTEGER DEFAULT 1,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(user_id, checkin_date)
);
```

### checkin_stats 表
```sql
CREATE TABLE checkin_stats (
    user_id TEXT PRIMARY KEY,
    total_days INTEGER DEFAULT 0,
    current_streak INTEGER DEFAULT 0,
    max_streak INTEGER DEFAULT 0,
    last_checkin_date DATE,
    total_points INTEGER DEFAULT 0,
    lucky_count INTEGER DEFAULT 0,
    makeup_count INTEGER DEFAULT 0,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

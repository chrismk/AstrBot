## 2. 核心模块说明

### 2.1 SubscriptionSource (订阅源)

订阅源是订阅系统的数据来源，支持多种类型：

| 类型 | 说明 | 示例 |
|------|------|------|
| `internal` | 内部榜单 | 搜索热榜、飙升榜 |
| `rss` | RSS/Atom订阅 | RSSHub、博客订阅 |
| `api` | REST API | 60s新闻、天气API |
| `webhook` | Webhook推送 | GitHub通知、CI/CD |
| `custom` | 自定义适配器 | 特殊数据源 |

### 2.2 SourceAdapter (订阅源适配器)

适配器负责从不同类型的订阅源获取内容：

```python
class SourceAdapter(ABC):
    @abstractmethod
    async def fetch(self, source: SubscriptionSource) -> List[SourceContent]:
        """获取订阅源内容"""
        pass
    
    @abstractmethod
    async def validate(self, source: SubscriptionSource) -> tuple[bool, str]:
        """验证订阅源配置"""
        pass
```

### 2.3 AccessLevel (访问级别)

控制不同用户对订阅源的访问权限：

| 级别 | 值 | 说明 |
|------|-----|------|
| PUBLIC | 0 | 所有用户可订阅 |
| REGISTERED | 1 | 注册用户可订阅 |
| MEMBER | 2 | 会员用户可订阅 |
| VIP | 3 | VIP用户可订阅 |
| ADMIN | 99 | 仅管理员可订阅 |

## 4. 配置管理

### 4.1 订阅源配置位置

订阅源配置存储在数据库中，通过 `/管理` 命令管理：

- **优点**: 动态管理，无需重启
- **权限**: 仅管理员可操作
- **备份**: 随数据库一起备份

### 4.2 预置订阅源

系统内置常用订阅源模板，管理员一键添加：

```python
# APIAdapter.PRESETS
PRESETS = {
    '60s': {
        'url': 'https://60s.viki.moe/',
        'parser_config': {...},
        'push_template': '📰 每日60秒读懂世界\n\n{content}'
    },
    'bing_wallpaper': {...},
    # 可扩展更多预置
}
```

### 4.3 自定义订阅源

管理员可添加自定义订阅源：

```yaml
# 示例: 添加RSSHub源
名称: 微博热搜
类型: rss
URL: https://rsshub.app/weibo/search/hot
描述: 微博实时热搜榜
访问级别: 会员
更新间隔: 1800  # 30分钟
```

## 5. 权限控制策略

### 5.1 订阅源权限

| 源类型 | 建议权限 | 说明 |
|--------|----------|------|
| 内部榜单 | PUBLIC | 基础功能，所有用户可用 |
| 60s新闻 | PUBLIC | 公共信息，免费提供 |
| RSSHub | MEMBER | 消耗服务器资源，会员专享 |
| 自定义API | VIP | 高级功能，VIP专享 |
| Webhook | ADMIN | 需要配置，管理员专用 |

### 5.2 订阅数量限制

```python
# 按用户等级限制订阅数量
SUBSCRIPTION_LIMITS = {
    AccessLevel.PUBLIC: 5,      # 普通用户最多5个订阅
    AccessLevel.REGISTERED: 10, # 注册用户最多10个
    AccessLevel.MEMBER: 20,     # 会员最多20个
    AccessLevel.VIP: 50,        # VIP最多50个
    AccessLevel.ADMIN: 999      # 管理员无限制
}
```

## 6. 扩展指南

### 6.1 添加新的订阅源类型

1. 创建新的适配器类：

```python
class MyCustomAdapter(SourceAdapter):
    async def fetch(self, source: SubscriptionSource) -> List[SourceContent]:
        # 实现获取逻辑
        pass
    
    async def validate(self, source: SubscriptionSource) -> tuple[bool, str]:
        # 实现验证逻辑
        pass
```

2. 注册适配器：

```python
source_manager.register_adapter(SourceType.CUSTOM, MyCustomAdapter())
```

### 6.2 添加预置订阅源

在 `APIAdapter.PRESETS` 中添加：

```python
PRESETS = {
    'my_source': {
        'url': 'https://api.example.com/data',
        'parser_config': {
            'data_path': 'result.items',
            'title_field': 'title',
            'content_field': 'summary'
        },
        'push_template': '📰 {title}\n\n{content}'
    }
}
```

### 6.3 自定义推送模板

支持的模板变量：

| 变量 | 说明 |
|------|------|
| `{title}` | 内容标题 |
| `{content}` | 内容正文 |
| `{url}` | 内容链接 |
| `{published_at}` | 发布时间 |
| `{icon}` | 源图标 |

## 7. 最佳实践

### 7.1 订阅源管理

1. **分级管理**: 根据资源消耗设置合理的访问级别
2. **定期检查**: 定期测试订阅源可用性
3. **错误处理**: 连续失败5次自动停用
4. **限流保护**: 设置合理的更新间隔

### 7.2 用户体验

1. **清晰分类**: 按类型展示可用订阅源
2. **权限提示**: 明确告知用户升级可解锁的功能
3. **推送控制**: 允许用户设置免打扰时段
4. **内容预览**: 订阅前可预览内容样式

### 7.3 运维建议

1. **监控**: 监控订阅源的成功率和延迟
2. **日志**: 记录推送日志便于排查问题
3. **备份**: 定期备份订阅源配置
4. **清理**: 定期清理过期的推送日志
